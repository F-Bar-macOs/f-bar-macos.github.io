How It Works

1. Connect Your Servers

Add your Laravel Forge account via secure Keychain. F-Bar pulls servers and sites instantly into the menu bar.

2. Monitor and Deploy

Track status live. Trigger deployments, edit scripts in Monaco Editor, view logs with syntax highlighting. Get native push alerts on completion.

3. Action Bar Access

Hit Cmd+Shift+Space for fuzzy search across actions. Keyboard-navigate recent commands or any operation—zero friction.

4. Stay Updated Effortlessly

Idle refreshes, auto-retries on errors, and smart caching keep everything current without overload.
